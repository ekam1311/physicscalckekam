# Physics Formula Calculator

**A beginner-friendly Python program** that calculates common physics formulas for kinematics, projectile motion, circular motion, and vector operations. It includes an optional symbolic calculus helper (requires `sympy`) to compute derivatives and integrals of simple time-dependent expressions.

## Features
- Kinematics: v = u + at, s = ut + 1/2 a t^2, v^2 = u^2 + 2as
- Projectile motion: time of flight, range, max height for a projectile
- Circular motion: centripetal acceleration
- Vector operations: dot product, magnitude
- Optional calculus helper using SymPy for symbolic derivatives/integrals

## How to run
1. Save `physics_calculator.py`.
2. (Optional) Create and activate a virtual environment.
3. (Optional) `pip install sympy` to enable calculus helper.
4. Run: `python physics_calculator.py`

## Example
Calculate range and max height for v0=20 m/s and angle=30 degrees.

## Notes
This project is designed for Class 12 students to demonstrate physics + coding skills. You can extend it with plotting (matplotlib), a web UI (Flask/Streamlit), or add saving/loading of results.
